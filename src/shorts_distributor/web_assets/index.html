사용 순서

  1. 채널과 플랫폼 저장

    계정 및 설정에서 본인 YouTube 채널, 대상 플랫폼, 계정 핸들과 검증 URL을 입력합니다.

  2. 플랫폼에 로그인

    플랫폼의 ‘로그인 연결’을 누르고 Chrome에서 로그인합니다. 돌아와 ‘로그인 완료’를 누르세요.

  3. 환경 점검 및 영상 선택

    환경 점검을 실행한 뒤 채널 영상을 불러옵니다. 처음에는 2편을 선택하세요.

  4. 미리보기 검토

    미리보기를 만들고 영상 순서, 최종 문구, 정책상 제외된 플랫폼을 확인합니다.

  5. 배포와 결과 확인

    게시 모드로 시작한 경우, 검토 확인 후 배포할 수 있습니다. 작업 기록에서 결과를 확인하세요.

앱 시작

PowerShell 7에서 프로젝트 폴더를 연 후 실행합니다.

.\Start-Multiuploader.ps1

게시 버튼을 사용하려면 게시 모드로 시작합니다.

.\Start-Multiuploader.ps1 -EnablePublishing

주소는 http://127.0.0.1:8765입니다. 앱을 종료하려면 실행한 터미널에서 Ctrl+C를 누르세요.

작업 결과 읽기

‘게시됨’은 게시 증거가 있고 추가 검증이 남은 상태입니다. ‘검증 완료’는 검증이 끝난 상태입니다. ‘확인 필요’는 계정 연결이나 플랫폼 화면을 확인하세요. 이전 게시 시도는 자동으로 반복하지 않습니다.
